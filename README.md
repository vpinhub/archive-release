# The VPX Preservation Archive

The virtual pinball community has a rich history of incredible, community-driven creations. Over time, due to broken links, site closures, or lost media, many fantastic Visual Pinball X (VPX) tables have disappeared from public circulation. 

This repository serves as a static archive to preserve these lost tables and ensure they remain available for cabinet owners and desktop players alike. 

## What You Will Find Here
* **VPX Tables:** Files that have fallen offline from primary community hubs.
* **Assets:** Associated files necessary for preservation, such as PUP packs.

*Note: This archive is strictly for preservation. No modifications have been made to the original files.*

---

## Preservation & Author Respect

This archive was created solely for the purpose of preserving abandoned or lost virtual pinball media. All credit for these tables belongs entirely to the original authors, modders, and developers who poured their time and passion into creating them. 

**Our Hosting Policy:** We make every effort to contact the original releasing authors to request explicit permission before adding any files to this archive. 

If you are the original author of a file hosted here and you would like your work removed from this archive entirely, or if you have a new official download link you would prefer we point to, please reach out to us in the **VPINHUB Discord**. We will honor requests immediately.
